# SmartPantryManager
Smart Pantry Manager Repository for Richfield Mobile App Development Assignment 2026

A Java Android Application that Suggests Recipes Based Strictly on Leftover Ingredients to Cut Food Waste.

Database Chosen: SQLLite
SQLite was chosen due to my familiarity with SQLite which would make development easier on tighter deadlines.

Setup Instructions
1. Download the Repository as .zip or clone repository
2. Open Repository in Android Studio
3. Run on the Android Studio Emulator
4. Ensure Android Emulator is configured and press run

Requirements:

Windows 10 64 bit and later
8GB RAM
Intel i5
Android Studio Qual 4.0
A Modern OS for Android Emulator
